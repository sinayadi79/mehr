# اپ مدیریت مأموریت‌های مهر

این پوشه یک وب‌اپ آفلاین (PWA) مخصوص آیفون است.

## امکانات
- تعریف، ویرایش، حذف، غیرفعال‌سازی و مرتب‌سازی خدمات
- مشخص‌کردن خدمات پرکاربرد
- محاسبه خودکار جمع قیمت‌ها
- ثبت مأموریت با کد یکتای افزایشی
- جست‌وجوی مأموریت با کد، نام، شماره، آدرس و وضعیت
- تغییر وضعیت مأموریت
- کپی خلاصه مأموریت
- ثبت مأموریت مشابه
- پشتیبان‌گیری و بازیابی JSON
- کارکرد آفلاین پس از نصب

## نصب روی آیفون
برای نصب واقعی به‌صورت Add to Home Screen، فایل‌ها باید یک بار روی یک سرویس HTTPS قرار بگیرند.
ساده‌ترین روش‌ها: GitHub Pages، Netlify یا Cloudflare Pages.

پس از بازکردن آدرس در Safari:
1. Share را بزنید.
2. Add to Home Screen را انتخاب کنید.
3. بعد از اولین بارگذاری، برنامه بدون اینترنت هم اجرا می‌شود.

## نکته مهم
اطلاعات در حافظه مرورگر همان آیفون ذخیره می‌شود. برای جلوگیری از حذف ناخواسته، مرتب فایل پشتیبان بگیرید.
